## 关于本仓库

## 占位符约定

本仓库为 **main 公开轨**，任何配置只以占位符形态出现：

| 占位符 | 含义 | 真值位置 |
|--------|------|----------|
| `PLACEHOLDER_HOST` | 部署目标主机 | private 仓 `vars.DEPLOY_HOST` |
| `PLACEHOLDER_USER` | 部署用户 | private 仓 `vars.DEPLOY_USER` |
| `PLACEHOLDER_PATH` | 部署目录 | private 仓 `vars.DEPLOY_PATH` |
| `PLACEHOLDER_PORT` | 服务端口 | private 仓 `vars.DEPLOY_PORT` |
| `PLACEHOLDER_SERVICE` | 服务名 | private 仓 `vars.DEPLOY_SERVICE` |
